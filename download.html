Download Ocraft

Ocraft is currently available as a Java .jar file.

Download from itch.io

How to run it

You need Java installed. Open Command Prompt in the folder containing the game and run:

java -jar ocraft.jar

If your downloaded file has a different name, use that filename instead.

Alpha warning
